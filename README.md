# 🤖 Tan-kung: Google Workspace Support Agent

Tan-kung is a specialized, friendly AI chatbot built to assist users exclusively with Google Workspace (Gmail, Drive, Docs, etc.). It features a conversation memory system, a Google-inspired UI, and support for both English and Thai.

## 🚀 Features
- **Specialized Knowledge:** Locked to Google Workspace support using System Instructions.
- **Persistent Memory:** Remembers context within a session using unique Session IDs.
- **Modern UI:** Material Design aesthetic with a custom "Tan-kung" avatar.
- **Fast & Lightweight:** Powered by **FastAPI** and **Gemini 2.5 Flash Lite**.

---

## 🛠️ Tech Stack
- **Backend:** Python 3.10+, FastAPI
- **AI Model:** Google Gemini 2.5 Flash Lite
- **AI SDK:** `google-genai` (Official Google Python SDK)
- **Frontend:** Vanilla JS, CSS3, HTML5
